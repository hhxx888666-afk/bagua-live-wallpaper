# Bagua Live Wallpaper

A clean Windows desktop live wallpaper featuring a sharp black-and-white rotating Bagua.

## Goals
- True desktop wallpaper behind desktop icons and taskbar
- Sharp vector-drawn Bagua; no blurry MP4 frames
- Slow continuous rotation
- No pause/resume UI
- Restore the previous Windows wallpaper when exiting
- No Visual Studio installation required for end users

## Build
The first implementation is intentionally dependency-light. See `src/` and `build.ps1`.
